About

What this site is and why it exists.

Cyberillc's Decomp World is a personal project that i made to show Unity game recompilations i've made.

Why decompile?

Decompilation is a technique that lets you reverse eningeer game code and understand how it works, most of the time, with games you can use decompiled code to make game mods or to access the game in the editor.
